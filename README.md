## 安装

1. Windows：运行EXE安装一次，之后从桌面或开始菜单打开。
2. Mac：解压ZIP，把ListeningSplitter.app放到应用程序目录，之后固定到程序坞。此包仅支持Apple Silicon。
3. 音频导入后按题试听、细化小句、校对文字；组卷页可排序、套用节奏并导出。
